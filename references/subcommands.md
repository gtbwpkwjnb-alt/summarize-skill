# 子命令一览（v8.2 反装饰对齐）

| 命令 | 功能 | 输出格式 |
|------|------|------|
| `总结 统计` | 全局统计 | `运行{N}次 \| 采纳率{NN}% \| 复发率{NN}%` |
| `总结 压缩` | 压缩归档 + headroom 双轨 | `{N}→{N} 条 \| ~{N}KB \| hash: {hash}` |
| `总结 知识库` | 查看知识库 | `{N}条 > 最近3条` |
| `总结 台账` | 查看台账 | `{N}条 > ✅{N} ⚠️{N}` |
| `总结 遗忘` | 清理记忆 | `{N}条可清理 > 建议 forget 最久未引用的2条` |
| `总结 深度 链` | 因果链分析 | `A→B→C` |
| `总结 深度 验证` | 出站验证 | `参考: {URL}` |
| `总结 深度 自检` | 对抗性自检 | `✅ 通过 / ⚠️ 疑虑` |
| `总结 深度 写入` | L0 升级提案（v8.2 重定义） | 温区高复发规则以**提案形式**呈递用户，详见 [references/deep-write.md](references/deep-write.md) |

> **v8.2 变更**：删除所有装饰性 emoji（📊📘📚📋🔗🌐🪖）。仅保留 `✅⚠️` 状态标记。`总结 深度 写入` 不再自动写入 L0，改为提案→批准→执行流程。
