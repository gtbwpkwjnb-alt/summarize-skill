# 模块 3：建议总结 — 精简版

### 轮转模式适配（v7）

模块3 负责错误收割与 5维分类分析。在 v7 轮转模式下，模块3 的额外职责：

1. **规则预生成**：每次错误分类后，必须生成 `→ 规则:`。没有规则的错误不进入轮转报告
2. **规则质量**：规则必须可执行（禁止 `下次注意` 等无效规则）
3. **跨 session 聚合**：读取温区/冷区历史，同类错误合并计数

轮转模式下的错误输出流向：
```
模块3 分类收割 → 生成 → 规则
                    ↓
          规则是否有效？ → 否 → 存温区但不进入轮转报告
                    ↓ 是
              进入轮转报告 ⚠️ 区块
```

## 3.1 链路优化

检测重复失败模式后输出一行优化建议，格式：

```
⚡ 链路: {模式} → {1句建议} | 依据: {N}次
```

检测模式（按序匹配，首个命中即输出）：
- 重复构建失败(≥2) → "建议前置检查脚本"
- 环境缺失 → "创建环境检测脚本"
- 重试≥2次未换方向 → "设2次失败自动换路"
- 同类错误≥3次 → "提升为项目约定"
- 技能堆积>8 → "建议技能总结审查"
- Headroom 降级 → "检查代理状态"
